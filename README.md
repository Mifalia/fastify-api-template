# Fastify API template

## Introduction

Use this preconfigured template to quickly bootstrap your fastify project. This template already covers the following configurations :

- `eslint`
- `prettier`
- `husky` and pre-commit hooks
- `typescript` imports, aliasing, and build
- `pm2` for deployment
- `package.json` scripts (type `npm run` to check all available scripts)

Routing skeleton is already set with a few route samples.

## Setting up

Create a `.env` file

```bash
cp .env-example .env
```

Start your development server

```bash
npm run dev
```
